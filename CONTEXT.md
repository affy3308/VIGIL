# VIGIL: Последний Оплот — контекст проекта для агента

> Этот файл — «память» проекта. Агент (Kimi) читает его при подключении к репо
> на любой машине и обновляет не реже раза в 24 часа при активной работе.
> Последнее обновление: 2026-11-26 (агент, вручную).

## Что это

Браузерный survival-шутер с видом сверху в сеттинге grim dark future
(референс — Warhammer 40 000, без лицензионных ассетов: всё процедурное).
Игра вдохновлена WH40k: орден космодесанта (референс геральдики — Экзорцисты),
враги — все основные фракции. Мобильная + десктопная игра (тач-стики / WASD+мышь).

## Стек и структура

- Vite + React-shell (React только монтирует канвас) + Three.js + TypeScript.
- Код игры: `app/src/game/` (не React!). Точка входа: `app/src/pages/Home.tsx`
  (канвас `id="game-canvas"` + `#ui-overlay`), `app/src/game/boot.ts`.
- Модули:
  - `game.ts` — оркестратор: состояния title/campaign/briefing/playing/upgrade/
    paused/gameover/victory; бой, пикапы, бусты, ульты, FX (кольца/лучи/пузырь).
  - `levels.ts` — генератор кампании: 3 сложности × 64 операции × 8 карт
    (7 волн + босс-волна), 8 фракций с биомами/боссами/эпиграфами.
    Гейт «Смертельной»: ★96 на ветеране + пройденный аналог на ветеране.
  - `enemies.ts` — 18 видов (10 пехотных + 8 боссов), AI, HP-бары, пулы.
  - `heroes.ts` — 12 героев (броня/статы/пассивы/ульта), разблокировка
    за звёзды кампании или покупка за реликты.
  - `shop.ts` — реликты (мягкая валюта), звёзды (рейтинг 1–3 за операцию),
    бусты перед забегом (Аегис/Литания/Фокус), гейты разблокировки.
  - `world.ts` — 8 биомов (пол/свет/препятствия), 4 layout'а препятствий.
  - `player.ts` — модели героев: GLB-архетипы (Tripo API), процедурные тела —
    fallback. GLB_SOURCES/GLB_HEIGHT/GLB_ROT_Y задают файл, рост и поворот
    каждого архетипа; debug-поворот: URL-параметр ?glbrot=<градусы>.
  - `bullets.ts` — пулы снарядов; свои летят ровно, вражеские вихляют/пульсируют.
  - `hud.ts` — весь DOM UI (экраны, чипы бустов, тосты, карта кампании).
  - `audio.ts` — Web Audio синтез + живые сэмплы (CC0 OpenGameArt) + музыка
    Kevin MacLeod (CC-BY, см. app/CREDITS.md).
- Тестовые хуки: `window.__vigil` (Game), `window.__gameProbe()`,
  `window.__GAME_READY__`. Приватные TS-поля доступны в рантайме:
  `__vigil["state"]`, `__vigil["applyBoost"]("shield")`,
  `__vigil["enemies"].spawn(kind,x,z,hpMul,dmgMul)` и т.д.
- Проверка перед каждой сдачей: `cd app && npm run build`, затем
  `CHROMIUM_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe" node scripts/verify-game.mjs`
  → должно быть `VERIFY OK`. Плейтесты пишутся временными скриптами в
  `app/scripts/temp-*.mjs` и УДАЛЯЮТСЯ перед сдачей вместе с
  `app/verification-shots/`. Dev-сервер не оставлять запущенным.
